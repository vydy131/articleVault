### [Синхронизация автоматом через гитхаб]
В левой менюшке должна появиться кнопка гита, она открывает панель коммитов

### уолтер убери свой [канбан] уолтер
Колонки toDo / inProgress / Done являются обязательными, чтобы было понятно кто чем занимается. Создавать карточки можно и нужно в меру собственной распущенности, дробить задачи необходимо в меру
Колонки ревью опциональны и нужны по большей части для правок частей текста самих статей, чтобы было понимание какой процент прошел через 2 пары рук

### Ссылки даются в двойных квадратных скобках ~~если кто пользуется обсидианом в первый раз~~
Можно делать ссылки-призраки, на еще ненаписанные страницы.
Одинарные квадратные скобки дают простой хайлайт.
